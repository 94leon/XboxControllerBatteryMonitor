# 手动验证清单（需真实手柄）

> 单元测试覆盖所有纯逻辑；本清单覆盖无法自动化测试的真实硬件路径。
> Toast/震动的触发技巧：把阈值临时调到高于当前电量（如电量 80% 时设警告 85 / 危险 82），
> 然后把手柄关机再开机——重连会重置阈值状态，低电判断立即生效。

- [ ] 蓝牙手柄连接：托盘图标显示精确百分比，tooltip 与菜单一致
- [ ] 蓝牙手柄断开：约 10 秒内图标消失/切换为"未发现手柄"
- [ ] 适配器手柄连接：图标显示估算百分比（10/40/70/100 之一）
- [ ] USB 有线连接：图标显示"w"，tooltip 显示"有线"
- [ ] 混合场景：蓝牙 + 适配器手柄同时在线，两台都出现且蓝牙显示精确百分比
- [ ] 多手柄：图标每 5 秒轮换，角标序号正确，菜单列出全部
- [ ] 低电量 Toast：按上述技巧触发，警告/危险两档文案正确
- [ ] 震动：单手柄场景触发低电时手柄震动约 2 秒（4 脉冲）
- [ ] 多无线手柄 + 蓝牙手柄低电：只收 Toast，其他手柄不震动
- [ ] 设置：修改阈值/关闭震动后保存，重启应用设置保留
- [ ] 设置窗口单开：设置已打开时再次点击托盘菜单"设置…"或双击托盘图标 → 已有窗口置前，不新开
- [ ] 蓝牙开关：系统关闭蓝牙 → tooltip 提示"蓝牙已关闭"；重新开启 → 60 秒内恢复（或重连手柄触发）
- [ ] 休眠恢复：系统睡眠再唤醒后电量继续刷新
- [ ] 单实例：重复启动无第二个托盘图标（已自动化验证 ✅）
- [ ] 浅色/深色系统主题：图标前景可见（切换主题后 ≤5 秒内跟随）
